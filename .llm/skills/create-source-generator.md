# Skill: Create Source Generator

<!-- trigger: source generator, isourcegenerator, generated code, hint name, analyzer payload, generator collision, generated accessibility | Adding or changing a Roslyn source generator | Feature -->

**Trigger**: When adding a source generator, changing generated source, or reviewing generator
output and its tests.

---

## Start at the Unity API floor

Unity 2021.3 loads Roslyn 3.8 for analyzers. Use `ISourceGenerator` and
`ISyntaxReceiver`; `IIncrementalGenerator` and `ForAttributeWithMetadataName` are newer than the
floor. The generator project targets `netstandard2.0`, `LangVersion` 9, and references the pinned
`Microsoft.CodeAnalysis.CSharp` 3.8 package. Generated source must also compile as C# 9 against
Unity's netstandard 2.1 profile.

## Generate names once, reserve them for the whole run

A name that is unique against the input compilation can still collide with another helper emitted
in the same run. A top-level enum `A_B` and a nested enum `A.B` both naturally produce
`A_BWEnumHelpers`.

- Reserve every generated type name in a run-local `HashSet<string>`.
- Check both the reserved set and `Compilation.GetTypeByMetadataName`.
- On collision, append a deterministic hash of the source type's identity, then keep checking.
- Make hint names unique with the same stable identity suffix; sanitized names alone can collide.
- Keep generation order deterministic and never depend on dictionary enumeration order.

## Accessibility is an intersection, never a widening

Compute the generated type's visibility from the enum and **every** containing type:

- Reject `private`, `protected`, `private protected`, and file-local enums or owners before
  emitting anything.
- The generated helper is `public` only when the enum and every owner are `public`; otherwise it
  is `internal`.
- A private enum nested in an internal type is still private. Do not let "owner is internal"
  replace the enum's own accessibility with a wider value.
- Reject enums nested in generic types: a non-generic static extension class cannot name them.
- Skip an enum whose type is `[Obsolete(..., true)]`; generated references would be compile
  errors. Members marked obsolete are safe when generated code uses numeric literals.

## Generated code rules

- Never reference the enum's members directly. Emit numeric literals so aliases cannot create
  duplicate `case` labels and `[Obsolete]` members cannot warn or fail.
- Duplicate values are aliases. Leave the value out of generated tables and delegate to the
  generalized path; the runtime owns which alias `ToString` reports.
- When generated code falls back to an existing extension method, call the static generic method
  explicitly (`EnumNameCache<T>.ToCachedName(value)`), never the same extension syntax, or it
  recurses into the generated method.
- Preserve an existing fallback even when a generated table is empty: an all-alias enum with
  display-name attributes must still reach `EnumDisplayNameCache`, not `ToCachedName`.
- Mirror the enum's accessibility on the generated class and methods.
- Emit `// <auto-generated/>`, generated-code attributes, and no secrets or machine paths.

## Generator implementation hygiene

- Assign `out` parameters just before returning; never default-assign them at method entry. The
  compiler should prove every path.
- Reuse one `StringBuilder` for the duration of one `Execute` call. Do not use `[ThreadStatic]`:
  generator instances may run concurrently across compilations, and a run-local builder removes
  the per-item allocation without shared state.
- Match the attribute by resolved symbol, not by syntax text. If the attribute type is unresolved,
  emit nothing.
- Generator diagnostics are warnings at most; taking a package upgrade must never fail a consumer
  build. Name skip reasons concretely.

## Tests that prove the contract

- Drive the real generator with `CSharpGeneratorDriver`, update the compilation, and emit it.
  Assert there are no compiler errors.
- Verify deterministic output across two runs.
- Test call-site binding: a concrete call targets the generated type; a constrained generic call
  targets the generalized fallback.
- Compile an enum + generated helper in assembly A, then consume the public helper from assembly
  B. A helper that is only tested in its own assembly can still be inaccessible to consumers.
- Cover name collisions, every rejected accessibility shape, aliases, empty enums, all underlying
  widths, flags combinations, obsolete members/types, and runtime-generated enums.
- Test runtime limitations only. Convert fixture constants to the required literal type before an
  API call; a fixture bug must fail, not become `Assert.Ignore` (see
  [honest-gates](./honest-gates.md)).
- Package the real DLL under `Runtime/Analyzers` with `RoslynAnalyzer` importer metadata. Add it
  to the shipped-analyzer verifier and to `Generator~/Directory.Build.props` so every owned .NET
  project self-hosts the exact binary.
